# Everything Pulse does

- **Projects:** every project in one table, Active or Closed: current phase(s),
  time elapsed, last status, a graph of the last eight weeks, and when the next
  report is due. A point on any status graph opens that week's report.
- **Project page:** report and next-report dates, status (Delayed, At Risk, On
  Track) and why, current phases, elapsed, days remaining, items that need
  stakeholders, the status of the last eight weeks, the timeline, objectives and
  the saved reports, five to a page. Edit the project, close it (and reopen it),
  start a new report or start from the last one.
- **Report view:** a submitted report opens on its own page, with newer and
  older, **New report from this**, **Edit report** and **Export**. Drafts open
  in the editor.
- **Edit after export:** a submitted report stays editable, for example after
  sharing the slides for an internal review. **Save** updates the report and its
  saved PDF. Its report date stays as submitted.
- **Lock:** once a report has been presented, **Lock report** freezes it: no
  more edits, and the server refuses saves to it or its PDF. It can still be
  exported. **Unlock** (with a confirmation) reopens it.
- **Project form:** name, team, customer and logo, dates, then phases or
  sprints. The project's ID (its folder and file names) comes from the name.
  Phases can overlap: a phase that runs alongside another sits on its own row of
  the timeline, in the form's preview and in the report. A name too long for its
  bar goes beside it, never over another bar.
- **Timeline:** bars show "Phase 2" or the sprint's name with dates (just the
  number when that doesn't fit), and a card per period below gives its state
  (Done, In progress, Not started) and full name. Sprint projects show five
  sprints, three before the current one, and each sprint's card shows its goal.
- **Sprint goals:** the report editor sets the covered sprint's goal (up to 50
  characters) and, optionally, the next sprint's as tentative (in italics).
  Submitting the report saves them to the project's sprints.
- **Closed:** a project you close moves to Closed. "Closed" is only ever said of
  those; an active project past its end date shows "Past end date".
- **Drafts:** a project form or report is kept as a draft while you type: a file
  on the server and a copy in the browser. Opening it again puts it back, with
  **Discard changes** to start over. Saving it for real drops the draft. A saved
  draft is listed with its status and **Continue**.
- **Open in two places:** a report or project form that is also open somewhere else
  shows an alert. A report saved there first can't be overwritten from here: your
  save is refused, with a **Reload** button, and what you typed comes back as unsaved
  changes for you to save or discard. On the project form the last save wins.
- **Reports can't replace each other:** a date that already has a report is refused.
  **New report** opens that week's draft, and saving a draft under a new date moves
  it.
- **Report editor:** one page in the order of the PDF. Page 1: dates, status and
  why, the phases the report covers (those running on its date; tick more or
  fewer by hand) and the objectives. Page 2: Accomplishments, Ongoing and
  Outstanding Tasks (Upcoming Goals for sprints), People and Process and
  Technology, each item typed Ask, Approval, Directive or FYI. Items take bold,
  italic and bullet lists; Ctrl/⌘ Enter adds the next one. **Preview report**
  shows the PDF pages exactly as they will be exported.
- **Cancel:** the report editor and the project form go back without saving.
  With unsaved changes, Cancel first asks "Leave without saving?" (**Keep
  editing** or **Discard changes**).
- **Export:** **Save and export** in the editor and **Export** on a saved report
  offer PDF and PowerPoint (.pptx). Saving for real always keeps the PDF on the
  server. The PowerPoint file has two 16:9 slides of native shapes and text laid
  out like the PDF. To use it in Google Slides, upload it to Google Drive and
  open it there.
- **PDF:** two A4 landscape pages. Page 1: status and why, key numbers, the
  status of the last eight weeks, the timeline and the objectives. Page 2: the
  week's work, items that need stakeholder action by type, and the legend. Long
  lists shrink to fit their box. Pages are captured at about 385 dpi.
